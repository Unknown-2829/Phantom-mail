2. Description of Service

Phantom Mail provides disposable email addresses on the @unkn0wn.qzz.io and @phant0m.qzz.io domains for receiving — and, with an account, sending — email. The Service includes:

  • Free Plan: Addresses that self-destruct 1 hour after generation, holding up to 10 emails; 1 saved address; 3 UI sends/day. API keys can receive only (10 emails/day) — API sending is blocked.

Sending requires an account. Anonymous sending is disabled — you must be signed in to send mail, and API sending requires a Premium API key.
